# Aim Tool 8 Ball

أداة Overlay لتوجيه الضربات في ألعاب البلياردو.

## بناء الـ APK تلقائياً عبر GitHub Actions

1. اذهب إلى تبويب **Actions** في المستودع
2. اختر workflow اسمه **Build APK**
3. اضغط **Run workflow**
4. بعد ما يخلص البناء (حوالي 3-6 دقائق)، اضغط على الـ run
5. من قسم **Artifacts** حمل ملف **AimTool8Ball-debug**

## المميزات
- Overlay شفاف
- خطوط توجيه + Bank Shot
- لوحة تحكم قابلة للسحب
